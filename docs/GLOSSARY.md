# 용어집

문서 라이선스: CC BY 4.0. 코드: GPL-2.0-only.

| 용어 | 뜻 |
|---|---|
| **Mingol** | 이 엔진의 이름 |
| **Mingol Script / `.mins`** | 자체 언어(Java식 클래스 + C식 문법, 정적 타입). 컴파일러 → 바이트코드 → VM |
| **VM** | `engine/script`의 스택 기반 바이트코드 가상 머신(mark-sweep GC, 코루틴 지원) |
| **ScriptHost** | 컴파일된 프로그램+VM을 소유하고 엔진 API를 스크립트에 노출하는 `engine/scripting` 객체 |
| **ScriptComponent** | `Script` 상속 클래스의 인스턴스를 GameObject에 붙이는 컴포넌트 |
| **핫 리로드** | 새로 컴파일 후 필드 이름+타입 기준으로 상태를 옮기고 VM을 교체 |
| **플러그인 ABI** | 공유 라이브러리가 `native` 함수를 이름으로 등록하는 순수 C 인터페이스(v1) |
| **`.mindev`** | 프로젝트 파일(JSON 텍스트): 이름, 엔진 버전, 씬 목록, 진입 씬, assetDirs/scriptDirs, `integrity` |
| **`.minseen`** | 씬 파일(JSON 텍스트): GameObject 계층 + 컴포넌트 속성, 에셋은 이름으로 참조 |
| **`.mingol`** | 배포용 읽기 전용 아카이브(선택 암호화·무결성). 실행 파일 뒤에 붙이면 단일 EXE |
| **ContentSource** | 플레이어가 파일을 읽는 추상화: 폴더 / 아카이브 / 내장 아카이브 |
| **표준 에셋 이름** | `builtin/box`, `<경로>#mesh0.0` 등 에디터·플레이어가 공유하는 에셋 이름 규칙 |
| **RHI** | 백엔드 중립 GPU 인터페이스(Vulkan 구현) |
| **RenderScene** | 렌더러 입력: 카메라·조명·그릴 항목의 평평한 목록 |
| **Forward / PBR** | 오브젝트마다 조명을 계산하는 방식 / 물리 기반 셰이딩(GGX) |
| **lavapipe** | Mesa의 소프트웨어 Vulkan 드라이버. 이 프로젝트의 유일한 검증 GPU |
| **헤드리스** | OS 창 없이 오프스크린 스왑체인으로 실행하는 모드 |
| **DrawList** | GUI의 출력(정점/인덱스/클립/텍스처 ID). GPU·소프트웨어 래스터라이저 모두 이것을 그린다 |
| **즉시 모드 GUI** | 매 프레임 위젯 함수를 호출해 UI를 만드는 방식(상태는 ID로 보관) |
| **스냅샷 실행 취소** | 변경마다 씬 전체를 `.minseen` 텍스트로 저장해 되돌리는 방식(에디터) |
| **재생 모드** | 시작 시 스냅샷, 정지 시 복원하는 에디터 실행 모드 |
| **고정 스텝** | 물리/`fixedUpdate`를 일정 간격(기본 1/60 s)으로 누적 실행하는 방식 |
| **세대 핸들** | 슬롯 번호+세대 번호. 재사용된 슬롯에서 옛 핸들이 무효가 됨 |
| **변이 테스트** | 구현을 일부러 망가뜨려 테스트가 실패하는지 확인하는 기법 |
| **골든 이미지** | 눈으로 확인 후 저장한 기준 이미지(회귀 가드, 정답 증명 아님) |
