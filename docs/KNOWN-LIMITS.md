"구현했지만 검증하지 못한 것"과 "아직 없는 것"을 구분해서 한곳에 모았다. 갱신 시 [STATUS.md](STATUS.md)와 함께 고친다.

## A. 검증하지 못한 것 (코드는 있음)
| 항목 | 상태 |
|---|---|
| Windows / MSVC | CI(`windows-2022`, vcpkg)에서 빌드와 CTest 25개 통과. 미검증: Win32 창·Vulkan 표면, 에디터/플레이어 실제 실행, `LoadLibrary` 실사용, PE 오버레이 단일 EXE 실행, GPU 테스트 실행 여부(러너에 GPU 없음) |
| 실제 GPU | lavapipe(소프트웨어)만. 성능·드라이버별 동작·실제 프레젠트 미검증 |
| 실제 오디오 장치 | Null 백엔드만 검증(ALSA/Pulse/WASAPI 미실행) |
| Wayland, 고DPI, 다중 모니터 | 미검증(Wayland 네이티브는 미지원) |
| CI 워크플로 | 첫 실행에서 Linux 잡 통과, Windows 잡은 의존성(vcpkg)·MSVC 이식성 수정 후 통과. Linux는 asan/tsan/valgrind 단계까지 통과했는지 Actions 기록 확인 필요 |
| 플러그인 ABI | Linux에서만 실행 검증 |
| 컴파일러 | GCC 13만. Clang/MSVC 미검증 |

## B. 기능 공백
- **렌더링**: IBL/환경광, 점광·캐스케이드 그림자, 알파 컷아웃, HDR/후처리, 컬링·인스턴싱, 사용자 머티리얼 셰이더 연결 API, SPIR-V 사전 컴파일/캐시.
- **에디터**: 비ASCII 글리프(한글), 자동 완성, 검색/치환, VM 줄 디버거, 다중 선택, 형제 순서 변경, 네이티브 파일 대화상자, 프리팹, 에셋 임포트 설정/자동 리임포트, 기즈모 로컬/월드 전환.
- **스크립트**: 엔진 API가 작음(로그·Vec3·GameObject만; 물리/오디오/입력/렌더 접근 없음), 객체 필드·코루틴 상태는 핫 리로드 시 이전되지 않음, 정적 변수 초기화, 버려진 코루틴의 `finally` 미실행, `ref` 매개변수는 리플렉션 호출 불가, 실행 시간 제한 없음.
- **플레이어**: 스크립트로의 입력 전달 없음(창 닫기만), 에셋 스트리밍 없음, 씬 전환 UI/스크립트 API 없음(C++ `loadScene`만).
- **패키징**: `.mingol` 압축 없음, 스트리밍 읽기/쓰기 없음(전체 메모리), 키 회전 없음.
- **물리/오디오**: 연속 충돌·조인트·소프트바디, HRTF·리버브·스트리밍 디코딩 없음. glTF 모프 타깃 등은 경고 후 무시.

## C. 설계상 감수한 것
- 암호화는 캐주얼 추출 방지 수준, 암호 구현은 감사 안 받음 → [SECURITY.md](SECURITY.md).
- 스크립트·씬·렌더러는 단일 스레드.
- 에디터 파일 대화상자는 경로 텍스트 입력.
- 에디터 편집 모드에서 컴포넌트 생성 시 스크립트 `onAwake/onEnable`이 실행된다.
